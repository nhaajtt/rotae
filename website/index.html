FAQ

FAQ (not very serious)

Is Rotae free?

Yes, 100% free and open source (MIT). There is no secret Pro version.

Do my files get uploaded?

No. Everything runs on your PC. Only actions that say so, like “To phone” or “Translate”, use the network, and only when you pick them.

Why does Windows warn me?

It is a new app without a paid code-signing certificate, so SmartScreen hasn't met it yet. Choose More info → Run anyway. The source is public on GitHub.

Video and audio don't work?

They need the free FFmpeg add-on: Settings › Add-ons › Download. One time. On Linux the installer brings FFmpeg along (or: sudo apt install ffmpeg).

Is there a Linux version?

Yes, for Ubuntu, Debian, Kali, Fedora and others (x86-64): one line in a terminal, or the .deb, .rpm and AppImage on GitHub. Drag a file to the glowing strip at the screen edge, or hold Shift while dragging on X11. Turn on Pentest user mode in Settings for forensics, capture analysis, recon and CTF tools, each running in a sandbox.

Is there a Mac version?

Yes, for Apple silicon Macs (M1 or later) on macOS 14 or later: paste the same curl line into Terminal. No "unidentified developer" prompt, since macOS only checks files a browser downloaded; the script checks the SHA-256 and signature instead. Press on a file in Finder, hold Shift and drag onto the wheel. The Mac version can also summarize, translate and hide private details with on-device AI.

Where is the app after installing?

It lives quietly in the system tray (the ⇄ icon by the clock). No window to keep open; just drag a file and hold Shift.
